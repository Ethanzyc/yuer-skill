# 育儿顾问 Skill

AI 驱动的个性化育儿指导系统，基于 Claude Code Skill 构建。

## 特点

- **个性化**：通过对话了解你的孩子，建立专属档案，所有建议都基于孩子的具体情况
- **循证**：建议注明来源（书名 + 策略名），基于 6 本经典育儿书的精读笔记
- **自我进化**：追踪建议效果，有效策略优先推荐，无效策略自动降权
- **问题分层**：L1 即时问题（快速响应）、L2 习惯养成（阶段计划）、L3 发展观察（长期跟踪）
- **上下文感知**：记录近期事件、活跃问题、季节因素，建议具有连续性
- **可视化**：轻量 Web 页面展示孩子档案、问题速查、建议追踪
